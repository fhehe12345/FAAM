# Reflection – Project Time Management

### Why is identifying the critical path important for project managers?
The critical path helps project managers prioritize tasks that cannot be delayed. It allows better resource allocation and ensures focus on activities that determine project duration.

### Which activity posed the highest scheduling risk?
Data Cleaning and Preprocessing posed the highest risk because unexpected data issues can significantly delay subsequent development and testing tasks.

### What trade-offs are involved when crashing a project?
Crashing requires additional resources or effort, which increases cost. While time is saved, quality and team workload must be carefully managed.
