# **Deliverables Verification Checklist – AI Medical Chatbot Project**

This checklist will be used to confirm that all project deliverables meet the required quality standards.

---

| **Quality Item**            | **Criteria**                                                                 | **Status** (Pending / Done) |
|-----------------------------|-----------------------------------------------------------------------------|------------------------------|
| **Dataset prepared**        | Cleaned, labelled, medically verified, no missing or inconsistent values    | Done              |
| **Knowledge base validation** | Medical information reviewed and aligned with trusted health sources (e.g., WHO, Mayo Clinic) | Pending |
| **NLP model performance**   | Achieves ≥ 85% accuracy (Precision, Recall, F1-Score); stable interpretation of symptoms | Pending        |
| **Response safety check**   | Provides non-diagnostic advice; avoids unsafe or misleading responses       | Done              |
| **Performance testing**     | Average response time < 2 seconds; low error rate                           | Pending               |
| **User interface (UI)**     | Simple, intuitive layout; buttons and links functional; smooth chatbot flow | Done              |
| **User experience (UX)**    | Messages clear, easy to understand; conversation flow natural               | Pending              |
| **Integration tests**       | Backend (model) and frontend (chat UI) connected and working properly       | Done              |
| **Security & privacy**      | User input handled safely; no sensitive info stored improperly              | Done              |
| **Documentation completeness** | Updated, error-free, includes system design, model description, testing results | Pending   |
| **Testing coverage**        | At least 10–15 test cases for accuracy, UI, and system behavior             |  Done              |
| **GitHub repository**       | All code pushed, version-controlled, well-organized folders, README added   | Pending              |
| **Project presentation materials** | Slides, diagrams, and demo prepared for evaluation                    | Pending               |
